# CombatSolver managed tools (frozen)

These projects are historical CombatSolver adapters, comparison harnesses, and
policy/query checks. They are intentionally outside `tools/` so ordinary Env
and Random Foreseer development cannot discover or build them by accident.

They are not part of the current build or acceptance path. Do not add new code
here. Reopening this directory requires an explicit project decision after the
generic Env and Random Foreseer API are complete.
