# Darv 先古事件源码批次

日期：2026-09-28。分支：`feat/generic-env-rf-api`。实现范围是通用 Env；CombatSolver 未修改。

## 源码语义

审阅了 `../Slay the Spire 2/src/Core/Models/Events/Darv.cs`、
`AncientEventModel.cs` 和 `Models/Relics/DustyTome.cs`。Darv 的
`ValidRelicSet` 按源码顺序包含 Astrolabe、Black Star、Calling Bell、Empty Cage、
Pandora's Box、Runic Pyramid、Snecko Eye；当前幕索引为 1 时追加 Ectoplasm 与 Sozu，
当前幕索引至少为 1 时追加 Philosopher's Stone 与 Velvet Choker。每个集合即使只有一项
也会调用一次 `Rng.NextItem`，随后用事件 RNG 做 `UnstableShuffle`。再调用一次
`Rng.NextBool`：真值选择洗牌后的前两项并追加 Dusty Tome，假值选择前三项。

Dusty Tome 的设置使用玩家 `Rewards` RNG，从角色牌池的已解锁牌中筛选 Ancient 稀有度，
排除 Archaic Tooth 的五张转生牌；获得后创建所选牌、升级一次并加入牌组。模拟器用
`RelicState.extra[0]` 保存所选的 canonical `CardId`，对应源码的 `SerializableCard`；
牌面 StringVar、hover tip 和预览动画属于当前 Env 尚未建模的表现层。

Darv 没有自己的 `IsAllowed` 覆盖，沿用 `AncientEventModel` 的 profile/Hook 检查。
当前 Env 使用完整 veteran profile，且没有先古 Hook 覆盖；因此默认允许进入。Darv 的
`DefineDialogues` 只影响先古对话（首次访问、角色访问次数 0/1/4 及通用对白），不改动
选项或 RNG，当前 Env 没有对话决策面，所以未伪造状态字段。

原版对 Pandora's Box 还有 `!RunState.Modifiers.Any(ClearsPlayerDeck)` 过滤。当前通用
Env 的 `RunData` 没有运行时 Modifier 集合，标准 profile 也没有清空牌组修正，因此本批按
标准 run 保留 Pandora's Box；接入 modifier API 时必须把该过滤补上，不能把当前实现当成
modifier 完整支持。

## 实现

- `game/Models/Events/Darv.h`：候选过滤、每组单项 `NextItem` RNG 消耗、洗牌、两/三项分支和 Dusty Tome setup。
- `game/Models/Relics/DustyTome.h`：角色牌池候选筛选、玩家 Rewards RNG、升级牌入牌组。
- `game/generated/AllModels.h`、`game/generated/Dispatch.cpp`：重新生成模型包含、`GenerateInitialOptions`、`AfterObtained` 和 `IsUsable` 分发。
- `docs/audits/map-source-inventory.json`：Darv 已登记 C++ 头文件且无 `SIM_NOT_PORTED` 标记。
