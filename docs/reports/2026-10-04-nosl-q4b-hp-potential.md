# NoSL Q4-b：HP 潜势塑形——结果

计划：[NoSL Q4-b 任务计划](../plans/2026-10-04-nosl-q4b-hp-potential.md)。
原始产物在 `artifacts/nosl-q4b/`、`artifacts/nosl-e01/q4b-*`、`artifacts/nosl-diag/`（不提交）。

## 结论

**按预先登记的判据：不稳定。** 判据要求两个学习器种子的 dev 平均层数区间下界都高于同种子对照的区间上界。
种子 1 满足（11.89 > 11.46），种子 2 不满足（10.56 < 11.24）。

两个种子的均值都比对照高（+1.64、+0.54 层），战斗里白白失血也确实少了，但只有两个种子，且种子间差异本身就有 1 层左右。
**现在不能说塑形已被证明有效**；要下结论需要更多种子，见文末登记的补充实验。

策略仍然 0 胜。主要的墙从精英移到了第一幕 Boss。

## 补充实验登记（写于任何补充运行之前）

为了回答“是否稳定”，各加一个学习器种子：

- F 臂种子 3、H 臂种子 3，设置与本实验完全相同（过滤器 1；`C = 0` / `C = 0.2`；2,000 万决策），同样的 dev 评价。
- 读法：先给出三个种子的逐种子表。再对 H − F 的平均层数差做分层自助法（先重采样种子，再在种子内重采样局，2000 次）的 95% 区间。
  区间下界大于 0 记为“塑形有改进”；否则记为“仍无定论”，并且不再为这个问题追加种子，除非有新的理由。
