# NoSL Q4-i：把“这条路上最少要打几个精英”给策略——结果

计划：[NoSL Q4-i 任务计划](../plans/2026-10-05-nosl-q4i-route-feature.md)（两个臂都在各自运行之前登记；第二个臂写在第一个臂的结果之后）。
原始产物在 `artifacts/nosl-q4i/`、`artifacts/nosl-q4f/greedy-curve.json`、`artifacts/nosl-q4g/override-avoid-elites.json`（不提交）。

## 结论

**路线信息有用，把它接到已有的最好策略上得到目前最好的结果：贪心 17.58 层，27.9% 的局进第二幕（起点 16.56 层、22.7%）。**
**仍然不是稳步前进：这一层在 500 万决策内涨完，后 500 万只多 0.08 层。**

| 臂 | 贪心平均层数 | 进入第二幕 | “有用”的门槛 | 稳步前进三条 |
|---|---|---|---|---|
| KFR（从零带路线特征，种子 1）| 16.22 / 16.57 / 16.68（1,000 / 1,500 / 2,000 万）| 14.1% / 15.6% / 18.9% | 17.2：不满足 | +0.46、+0.11 不满足；第 3 条满足 |
| KFR-w（KF 种子 2 的 3,000 万检查点接上路线特征）| 16.56 → 17.50 → 17.58（3,000 / 3,500 / 4,000 万）| 22.7% → 26.7% → 27.9% | 17.56：满足 | +1.01 满足；+0.08 **不满足**；第 3 条满足 |

## 起因：三成的局死在没有选过的精英战里

见计划“已经知道的”。KF 策略在岔路口几乎从不选精英（241 次里 0–8 次），却每局打 0.7–0.85 场第一幕精英战、其中约四成是死：
精英是几步之前选的路上唯一的后继。按“路上精英最少”改选地图节点（脚本替换，其余不动），KF 种子 2 的贪心结果从 16.55 层到 17.91 层（+1.36，标准误 0.13）。

## 改动

`--features 3`：地图决策时，每个可去的节点多两个数——从它到本幕终点任意一条路上最少有几个精英、比当前最好的选项多几个。
在观察里已有的地图节点上从后往前做一遍最短路，观察格式不变。向量化的实现与 `override_eval.py` 里的逐节点实现在随机分层图上逐值相同；
把第 2 档的检查点扩成第 3 档，输出逐值不变。

## KFR：从零训练

20,029,440 个决策，墙钟 3,988 s，12.0 万局，0 个失败、0 次超时，0 胜。

| | 1,000 万 | 1,500 万 | 2,000 万 | KF 两个种子同期 |
|---|---:|---:|---:|---|
| 贪心平均层数 | 16.22 | 16.57 | 16.68 | 15.03 / 15.58，15.42 / 15.48，16.46 / 15.91 |
| 贪心：每局第一幕精英战 | 0.51 | 0.39 | 0.32 | KF 种子 2 在 3,000 万：0.85 |
| 训练曲线窗口（采样） | 14.50 | 15.13 | 15.89 | 13.79 / 14.62，14.40 / 14.51，15.46 / 15.03 |
| 打到 Boss 的局占比 | 56.5% | 64.4% | — | 约 50% |
| Boss 胜率 | 15.1% | 14.2% | — | 20%–28% |

- 策略学会了绕开精英，1,000 万时就到了 KF 在 2,000 万才有的水平。
- 但走到 Boss 的局多了、打赢的少了：少打精英就少拿遗物，Boss 战打掉的比例停在 0.70 左右（KF 是 0.72–0.75）。两头一抵，2,000 万时只比 KF 高半层。
- 训练曲线的三条判据它全满足（+1.39 / +0.76 / 9.0% → 14.3%），贪心的不满足：训练曲线这一段涨的多半是采样和贪心之间的差距在收窄
  （1,000 万时差 1.7 层，2,000 万时差 0.8 层）。这再一次说明要看贪心。

## KFR-w：接到 KF 种子 2 上

KF 种子 2 的 3,000 万检查点扩成第 3 档（新层从零起步），接着训练 10,014,720 个决策，墙钟约 2,100 s，0 个失败、0 次超时，0 胜。
扩过的模型用新的优化器，学习率从 1.33e-4 起步（这条线当时的值），之后照旧随 KL 调整。

| | 3,000 万（起点） | 3,500 万 | 4,000 万 |
|---|---:|---:|---:|
| 贪心平均层数（标准误） | 16.56（0.14） | 17.50（0.15） | 17.58（0.15） |
| 贪心：进入第二幕 | 22.7% | 26.7% | 27.9% |
| 贪心：每局第一幕精英战 | 0.85 | 0.78 | 0.72 |
| 训练曲线窗口（采样） | 15.81 | 16.44 | 16.81 |
| 打到 Boss 的局占比 | 60.7% | 67.2% | 71.0% |
| Boss 战打掉的比例 / Boss 胜率 | 0.755 / 33.2% | 0.767 / 33.4% | 0.767 / 33.7% |

- 水平到了 17.58 层，接近脚本替换的 17.91 层，Boss 胜率没有掉。
- **登记的机制判据不满足**：每局精英战只从 0.85 降到 0.72，没有降到 0.4 以下。它没有照“精英最少”去走，却多了十个百分点的局走到 Boss。
  它拿这两个数做了什么，没有查（原生前向还没有这一档，逐决策诊断工具用不了）。
- 前 500 万决策涨了 0.94 层，后 500 万 0.08 层。

## 已知限制

- KFR、KFR-w 各一个种子。
- 原生前向（`nosl/policy_net.cpp`）没有第 3 档：这两个策略现在不能导出、不能上实机、不能用逐决策诊断。要补同一遍最短路并做数值对照。
- 2,000 个固定种子被反复用来比较快照，不是留出集；dev/test 没有动。
- 没有做正版回放（E01）。
