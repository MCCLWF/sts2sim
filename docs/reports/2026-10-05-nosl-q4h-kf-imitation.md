# NoSL Q4-h：在 KF 上加教师模仿项——结果

计划：[NoSL Q4-h 任务计划](../plans/2026-10-05-nosl-q4h-kf-imitation.md)（写于任何 KF + 模仿项的运行之前）。
原始产物在 `artifacts/nosl-q4h/`、`artifacts/nosl-q4f/greedy-curve.json`（不提交）。

## 结论

**没有用，而且差很多。** KFI（KF + Q4-c 的模仿项和同一批 12 万条教师示范）在 2,000 万决策时贪心 11.92 层，
登记的门槛是 17.2 层，KF 两个种子是 16.46 和 15.91 层。按计划不跑种子 2。

这个结果只说“现有的这批示范、这样加进去，在 KF 上是有害的”。它不说明在学生自己走到的状态上重新标注没有用。

## 怎么读

- 策略把示范背了下来（一致率 97%），战斗内的熵压到 0.18，Boss 战只打掉 46% 的血——比不带模仿项、不带 Boss 信号的 H 臂（55%）还低。
- 示范是教师看着真实未来、在教师自己走到的状态上打出来的。照着它出牌的策略看不到那些未来，也走不到那些状态。
- **和学习率规则搅在一起，分不开**：模仿项让每轮的策略变化变大，`--target-kl` 就一路把学习率从 3e-4 压到 0.4e-4，强化学习那一半跟着慢下来。
  Q4-c 用固定学习率时模仿项的效果是一正一负（+1.96 / −0.98 层），没有这么差。所以这里的坏结果有多少来自示范本身、多少来自这两项的相互作用，没有测。
- 预先登记的“一并报告”里，每回合漏挡/多挡和 Boss 之前的死亡占比没有做（要另跑 dev 评价和逐决策诊断）；结论已经很清楚，没有再花这份机器时间。
