## Change

Added `game/Models/Relics/ToastyMittens.h`. The hook returns for a non-owner, flashes, selects one card from hand through `CardSelectCmd::FromHand`, exhausts each selected result, and then applies the relic's `StrengthPower` dynamic variable to the owner. Since the selection result is empty for an empty hand, the final Strength application still runs, matching source order.

The source's localized `ExhaustSelectionPrompt` is presentation text. The generic Env selector API identifies the selection as `FromHand` and does not expose a localized prompt parameter.
