# NoSL Q4-k：六处改动合在一起从零训练——结果

计划：[NoSL Q4-k 任务计划](../plans/2026-10-05-nosl-q4k-best-recipe-from-scratch.md)（写于任何合并设置的从零运行之前）。
原始产物在 `artifacts/nosl-q4k/`、`artifacts/nosl-q4j/x1/`、`artifacts/nosl-e01/q4j-x1-greedy/`、`artifacts/nosl-q4f/greedy-curve.json`（不提交）。

## 结论

1. **不是稳步前进。** 合并设置（KFRX）从零训练 3,000 万决策，贪心水平在 1,000 万 → 2,000 万这一段满足全部三条，在 2,000 万 → 3,000 万这一段不满足；
   计划要求两段都满足。按计划不跑种子 2。
2. **没有复现分阶段那条线的水平。** KFRX 最高的快照是 17.04 层（2,500 万），门槛是 17.9；分阶段那条线是 18.4。一开始就多探索，学得比后加要慢。
3. **目前最好的策略仍是分阶段那一条**（Q4-j 的 X1：KF 种子 2 → 接路线输入 → 局外熵系数 0.05，共 5,000 万决策）。这一步把它在 dev 上评价了、
   在正版里回放了，原生前向也补上了它需要的输入：**dev 贪心 18.66 层（17.89–19.44），200 局里 65 局进第二幕，200 条轨迹正版回放全部相同。**

七个设置、八条曲线，没有一条在 2,000 万决策之后还按登记的门槛在涨。**同一个设置加长训练没有用；现在不做大批量训练。**

## KFRX：从零，3,000 万决策

过滤器 1、固定分母 HP 潜势、`γ = 1`、`--boss-damage 0.3`、`--target-kl 0.01`、`--features 3`、`--entropy-out 0.05`，种子 1。
30,013,440 个决策（977 轮），墙钟 5,995 s，18.1 万局，0 个失败、0 次超时，0 胜。一次一个训练、6 个采样进程。

| | 1,000 万 | 1,500 万 | 2,000 万 | 2,500 万 | 3,000 万 |
|---|---:|---:|---:|---:|---:|
| 贪心平均层数（标准误 0.09–0.12） | 15.06 | 16.09 | 16.49 | 17.04 | 16.43 |
| 贪心：进入第二幕 | 4.2% | 12.8% | 14.2% | 14.9% | 16.0% |
| 贪心：每局第一幕精英战 | 0.33 | 0.42 | 0.42 | 0.40 | 0.52 |
| 训练曲线窗口（采样） | 13.63 | 13.44 | 14.32 | 14.37 | 14.61 |
| 学习率（×1e-4） | 2.0 | 2.0 | 1.33 | 1.33 | 1.33 |

| 判据（贪心快照） | 1,000 万 → 2,000 万 | 2,000 万 → 3,000 万 |
|---|---|---|
| 1. 这一段 ≥ 1.0 层 | +1.43，满足 | −0.07，**不满足** |
| 2. 后 500 万 ≥ 0.3 层 | +0.41，满足 | −0.61，**不满足** |
| 3. 进入第二幕 ≥ 5% 且高于段首 | 14.2%（4.2%），满足 | 16.0%（14.2%），满足 |
| 复现：任一快照 ≥ 17.9 层 | 最高 17.04，**不满足** | |

- 3,000 万那一点取的是最终检查点（第 977 轮）；`--keep-every 163` 的下一个快照是第 978 轮，运行在它之前结束。
- 2,500 万到 3,000 万掉了 0.6 层。单个快照之间有 ±0.4 层左右的来回（K 那条线上也是），所以“2,500 万时 17.04”和“3,000 万时 16.43”都不能单独当水平；
  可以确定的是它没有在涨。
- 和 KF（不带路线输入、局外熵 0.01）比，KFRX 前 1,000 万明显慢（Boss 胜率 5% 对 15%–25%），之后追上，2,000 万时与 KF 同一水平。
  路线输入和多探索在从零训练里没有显出分阶段时的那两截。一个种子，说不清是配方的问题还是种子的问题。
