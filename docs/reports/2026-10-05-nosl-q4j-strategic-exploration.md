# NoSL Q4-j：局外决策多探索，贪心水平还涨不涨——结果

计划：[NoSL Q4-j 任务计划](../plans/2026-10-05-nosl-q4j-strategic-exploration.md)（写于任何带 `--entropy-out` 的运行之前）。
原始产物在 `artifacts/nosl-q4j/`、`artifacts/nosl-q4f/greedy-curve.json`（不提交）。

## 结论

**有用，仍然不是稳步前进。** 把战斗之外的熵系数从 0.01 提到 0.05，接着训练 1,000 万决策：

| | 4,000 万（起点） | 4,500 万 | 5,000 万 |
|---|---:|---:|---:|
| 贪心平均层数（标准误） | 17.58（0.15） | 18.44（0.15） | 18.38（0.14） |
| 贪心：进入第二幕 | 27.9% | 32.5% | 29.7% |
| 贪心：每局第一幕精英战 | 0.72 | 0.52 | 0.51 |
| 训练曲线窗口（采样） | 16.81 | 15.44 | 15.64 |
| 战斗之外的熵 | 0.25 | 0.65 | 0.67 |

| 判据 | 结果 |
|---|---|
| 5,000 万 − 4,000 万 ≥ 1.0 层 | +0.80，**不满足** |
| 5,000 万 − 4,500 万 ≥ 0.3 层 | −0.06，**不满足** |
| 5,000 万时进入第二幕高于 27.9% | 29.7%，满足 |
| 有害（低于 17.08 层） | 否 |

**贪心 18.4 层是目前最好的策略。** 和前面五处改动一样：500 万决策内涨完（+0.86），之后不动。

10,014,720 个决策，墙钟 2,127 s，5.05 万局，0 个失败、0 次超时，0 胜；学习率在 0.59–1.33e-4 之间。一个种子、一条线。

## 怎么读

- 假设的方向是对的：局外多试，采样的表现掉了 1.2–1.4 层（多出来的随机选择），取最大概率动作的策略反而强了 0.8 层。
  critic 见过的选项多了，最大概率的那个选得更准。
- **采样和贪心现在差 2.7 层**（15.6 对 18.4）。部署和评价都应当取最大概率动作；训练曲线已经完全不能当水平看。
- 它拿探索换来了什么（拿了哪些以前不拿的牌、路线怎么变的）没有查：这条线的模型是第 3 档输入，原生前向还没有，逐决策诊断用不了。
  每局精英战从 0.72 降到 0.51 是能看到的一处。

## 六处改动之后

| 设置（每一行在上一行的基础上） | 贪心水平（2,000 个固定种子） | 进入第二幕 |
|---|---:|---:|
| H（Q4-b） | dev 上 13.3 | 3% |
| + Boss 伤害信号、固定分母潜势、`γ = 1`（K） | 14.4–15.2 | 8%–10% |
| + 学习率随 KL 调整（KT） | 15.4 | 10% |
| + 牌面特征（KF） | 16.0–16.6 | 20%–23% |
| + 路线输入（接在 KF 种子 2 上） | 17.6 | 28% |
| + 局外熵系数 0.05 | 18.4 | 30%–32% |

KF 种子 2 这一条线上，每 1,000 万决策加一处改动：15.91（2,000 万）→ 16.56 → 17.58 → 18.38（5,000 万）。每一段的增量都在改动之后的头 500 万决策里；
不加改动的那一段（2,000 万 → 3,000 万）是 +0.65，其中后 500 万 +0.14。

**同一个设置加长训练仍然没有用；每加一处对的改动，半小时内见效。**

## 已知限制

- 一个种子、一条线；没有在第二条线上重复。
- 2,000 个固定种子被反复用来比较，不是留出集。dev/test 没有动。
- 原生前向没有第 3 档输入：这个策略现在不能导出，不能上实机，不能做正版回放和逐决策诊断。
