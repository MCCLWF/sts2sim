# Pael initial option generation port

Date: 2026-09-27.

## Preconditions

- Read `AGENTS.md` and `docs/audits/pitfalls.md`.
- Inspected the fixed v0.111.0 sources `Models/Events/Pael.cs`, `Models/AncientEventModel.cs`, `Models/EnchantmentModel.cs`, `Models/Enchantments/Goopy.cs`, `Entities/Players/Player.cs`, and the `AddsPet` overrides on Byrdpip and Pael's Legion.
- Confirmed the generic Env exposes `AncientRelicOption`, `Rng().NextItem`, card tag/removability queries, and `event_allowed::BaseCanEnchant`.

## Change

Added `game/Models/Events/Pael.h`. It materializes all candidates in the source order, draws from pool 1 before constructing pool 2, and makes the pool 2 eligibility checks in order. The Goopy check matches the base predicate plus `CardTag::Defend`; removable count uses `CardModel::IsRemovable()`.

The second pool duplicates its current entries before appending PaelsGrowth, matching `List.AddRange(list)` while retaining the same option states. Pool 3 is built after the second draw, and PaelsLegion is appended only when the exact source `HasEventPet` condition is false. The event performs the same three local RNG selection calls and uses ancient relic options.

The shared `event_allowed::HasEventPet` helper also considers the content-table `spawns_pets` flag, while the original `Player.HasEventPet()` checks only `AddsPet` and Byrdonis Egg. The new Pael implementation therefore uses a local predicate based on the two `AddsPet` overrides confirmed in source: Byrdpip and Pael's Legion.

Subsequent explicit stops are `PaelsTears.AfterSideTurnStart` and `PaelsWing.ShowCounter`; aggregate replay after this change reached 4025/5684 decisions across eight traces, with three complete runs, four Unported stops and one unrelated Crusher combat divergence on the SEED0003 policy 1 path.

## Limits

This change ports only initial option generation. It does not implement Pael relic effects. The chosen option arrays and immediate successor RNG were validated on the two original traces; unchosen combinations remain to be tested.
