## 框架改动

- 新增 `game/Models/Events/AllowedHelpers.h`，集中实现共享的遗物、宠物、金币和附魔可用性判定。
- 为部分移植事件保留 `SIM_NOT_PORTED` 标记，并运行 `refresh_not_ported.py`、`gen_dispatch.py` 更新生成分发。
- 事件奖励使用现有 `RewardsCmd::OfferCustom`；牌组操作使用 `CardSelectCmd`、`CardPileCmd`。
- C# canonical vars 在导出内容中缺失的事件（例如 DrowningBeacon、SunkenStatue）使用源码中的固定值，并在需要时用事件 `extra` 保存状态；没有改动 `content/generated` 数据表。

## 已知限制

- 计划要求的完整 L4 仍会在未移植的卡牌和上述复杂事件处停止；本次验收标准是无 `diverged`，不是让所有内容都继续到第一幕 Boss。
- oracle 对 `DenseVegetation`/`JungleMazeAdventure` 的日志仍有游戏端 `NullReferenceException`；这不属于模拟器分歧，已保留在结果说明中。
- 事件选项中的 hover tip、VFX、等待和动态本地化替换属于表现层，按现有无头框架省略；状态和 RNG 抽取顺序按源码保留。
