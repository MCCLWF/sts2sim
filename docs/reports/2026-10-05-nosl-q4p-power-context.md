## 结论

**未通过预先登记的继续门槛，本轮不追加训练、不替换 X1。** P 相比同预算 C 多 .4775 层（配对 95% 区间 [.2001,.7549]），相比 X1 多 .2875 层（[.0155,.5595]）。两项区间均在零以上，但效应均小于事前要求的 .5 层。单个学习 seed 的正向结果保留为研究证据；不将它解释成稳定进步或高水平验收。

公开能力归属开关、原生格式及诊断已实现，默认关闭。高水平 Silent A10 整局 NoSL 尚未实现，三种策略各 2000 局均 0 胜。

## 输入与合同

独立 `power_context` 开关按公开 Power token 的能力 id、显示数量和持有者序号聚合。能力 embedding 乘数量的 log/clip 尺度后，零初始化共享线性层加入玩家 global token 或对应 Enemy token；没有能力的持有者不加偏置。仅使用现有公开表，schema 1、奖励、规则、搜索均未改变，features 3 保留，未启用 Q4-l 的 deck-summary。

Python/C++ 同时支持该开关；新原生格式 3 记录 features/power-context，格式 1/2 继续读取。为不同 Torch 版本显式将 scatter index 转 int64；训练 forward 原本已将输入转 long，此修正不改变训练数值。已有 separate critic 的新层也零初始化。

上一轮 1248 个公开教师标签中，1006 行（约 80.6%）有敌方能力、489 行有玩家能力；X1 与教师动作一致率分别 40.46% / 43.35%。这是覆盖检查，不能推出能力归属造成失误，也没有据此改变本轮配置。P 的首次保存权重确认开关为 true、新层权重范数 .3350、偏置范数 .01998，均有限；新层实际参与学习。
