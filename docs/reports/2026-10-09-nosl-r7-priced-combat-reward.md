## 诊断：战斗训练为什么不动

停训之后做的，都不是登记的比较，都只用训练数据与已有的标签。

**一、策略梯度几乎全是噪声。** 给训练器加了一个只量不改的模式（`nosl.combat_ppo --gradient-check K`）：在基线的训练器检查点（第 1742 次迭代，旧回报，R5 的规则）上连采 24 个互相独立的批次（每批约 2.4 万个战斗决策，就是一次 PPO 迭代的量），每批算一次策略梯度（每个样本一次、ratio = 1、与更新时相同的归一化优势），不做任何更新：

| | |
|---|---:|
| 两个批次的梯度之间的余弦（276 对的均值） | **0.0015** |
| 前 12 批的均值与后 12 批的均值之间的余弦 | 0.076 |
| 单批梯度的范数 / 24 批均值的范数 | 0.472 / 0.099（纯噪声时应为 0.472 / √24 = 0.096） |

也就是说一次迭代的梯度里，方向上可重复的部分只占千分之一点五；要把余弦提到 0.5，得把约 680 个批次（两千万决策）平均成一步。**现在每一步更新有 99.8% 是噪声，PPO 在这个策略附近做的是随机游走**——这解释了从第 650 次迭代起四千万决策没有净变化，也解释了换回报之后先变差：换回报只是换了噪声的方向，策略被推离原地而没有被推向更好。R3 里 PPO 有过提高，是因为那时第二幕的战斗离好还很远，信号大；现在这部分已经拿完了。

**二、一步前瞻的标签是真信号，但网络学到的东西不外推。** 用 R4 留下的 13.6 万个决策的前瞻标签（每个候选动作 8 个重采样副本上的配对差及其标准误）：

- 标签的方差里只有 27% 是采样噪声（第一幕弱怪 10%，第二幕精英与 Boss 约三成）；其余是候选动作之间真实的差别（以“活下来 = 3、一条血 = 1”计，标准差 0.02–0.26）。所以 R3、R4 里“学不到”不是因为标签是噪声。
- 把优势回归训久一点（学习率 1e-3，30 轮）：训练损失从 0.039 慢慢降到 0.028（训练集上解释掉约三成），**留出集上的解释方差在第 9 轮到 0.075 之后一路掉回 0**，按预测换动作的收益始终在 0 附近。网络能背下训练集，背下来的东西对没见过的局面没有用。

合起来：（一）用带噪声的整场回报做策略梯度，在现在的策略上要多出两到三个数量级的样本才有方向；（二）用模拟出来的优势直接教，信号是真的，但 13 万个决策远不够这个网络学出能外推的规律——要么标签多一个数量级以上，要么换一种让规律更容易外推的表示（现在的手牌 token 里没有牌面上显示的、算过各种修正之后的伤害和格挡数值，敌人的 HP、格挡、意图伤害在另一类 token 里，“这张牌打不打得死它”“这回合挡不挡得住”要网络自己跨 token 做算术）。

## 顺带：实机执行的回合动作数上限

R4 起就记着的一个部署缺口：策略从不主动结束回合，碰到不花费用的牌可以一直打下去；模拟器里这种局靠 6000 步上限截断（十万局里一两局），真实游戏里没有任何东西会让它停。这里补上，与本项的实验无关：

- `nosl::Actor`（原生 actor，干跑与实机 Mod 共用）记自己在同一个战斗回合里做了多少个决策；到 300 个之后，只要“结束回合”合法就结束回合。策略包里可以用 `turn_cap N` 改（0 = 关）。它只读公开观察里的回合数和自己的计数。评价与训练用的 Python 通路没有这条上限（那里仍靠步数上限截断，如实计为截断）。
- 默认值下行为不变：`NR5EVAL000067` 的干跑 776 条记录与改动前逐条相同，没有一次触发。把上限设成 6 时：整局照常跑完，4 次触发全部是“结束回合”，都发生在同一回合已有 6 个决策之后。
- 重新构建的执行库在真实游戏里跑了同一个种子的影子、直连各一局：**2 / 2 打到游戏自己的终局，776 个动作与干跑逐个相同**，影子模式 775 个决策的编码一致。
- 没有验证的：真实游戏里上限真的被触发的那种局（需要一副能无限循环的牌组，没有现成的种子）。

## 结论

1. **登记的问题：无效。** 按数据定价的战斗回报没有让 PPO 学会省血，三个检查点都显著低于基线；没有采用，没有留出评价，最终组合仍是 R5 的。
2. 回报表本身是一个可用的测量：进阶 10 时一整条血和活过一场差不多值钱；但“药水值 0.2–0.8 条血”这类数是观察性的，R1 的脚本对照说留药水的净效果接近零，不能当因果用。
3. **战斗训练三次不动的原因找到了**：策略梯度的信噪比极低（批间余弦 0.0015）。继续用同样的办法加训练量没有意义，除非多出两三个数量级。
4. 一步前瞻的标签有七成是真信号，现有网络在 13 万个决策上学不出能外推的东西。
5. 实机执行器多了回合动作数上限的兜底，默认不改变任何行为。

## 下一步的方向（未登记）

战斗这一侧只剩两条路是有依据的：把前瞻标签放大一个数量级并量学习曲线（两个点已有：3.4 万与 13.6 万，留出解释方差 0.015 → 0.05）；或者先改表示（把牌面数值和“打不打得死、挡不挡得住”这类关系直接给网络），在现有标签上看留出解释方差能不能明显抬高，再决定放大哪一种。后者便宜，应先做。局外一侧，门口模型还没有用到地图路线上。
