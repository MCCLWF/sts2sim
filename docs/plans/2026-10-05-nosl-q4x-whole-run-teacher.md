# Q4-x：完整跑局的离线战斗教师先导

基线 main c230250。目标是检验完整跑局的战斗教师能否提供后期覆盖和真实通关信号，为高水平 Silent A10 NoSL 的新训练课程选择依据。Q4-o/u/v 的少量早期战斗标签拟合阴性结果保持不变；不延长该路线，不把搜索教师结果当 NoSL 胜率。

## 固定方案

- 原版 v0.111.0，Silent A10，全解锁老档案、正常新局，无 HP/牌组/遭遇/RNG 注入。实际 oracle begin 必须 TestMode=false。
- 战略和无法得到完整胜利路线的战斗由冻结 X1 公开观察贪心策略执行；公开 schema1、features3、actor_filter1，X1 SHA 6fb5f1955a11d55175d348659460ce459017baa018f7cf9242a671ba19266703。
- 每场战斗首个普通 combat 决策一次原始 CombatSolver 0.50.0/9a4489d 搜索，beam30/nodes10000/软10000ms/DOP1，每个宿主90秒，不扩大预算、不重搜、不补种子。初始战斗选牌仍用公开学生。教师属于离线特权参照，在线 NoSL 路径不调用搜索。
- 每个根由当前学生/教师历史转换为原版动作前缀。宿主新增可选准确 root-decision，不能仅靠层数混淆同层连续战斗。搜索前后完整根/continuation 不变；只接受预测存活完整胜利，重新从种子原版执行冻结路线，检查端点及 L4 所有字段，再逐行公开标签导出与训练 ABI 核验。
- 将已核验的教师标签应用到同一个独立 Env/actor-filter 历史，核对全部公开表，继续学生战略至下一战。旧脚本前缀和原公开选择须一致；故障隔离并停止该局，不伪装死亡或换根。
- 完整终局另从种子回放最终动作历史，正常 oracle 与严格 L4 全决策/资源/RNG/真实终点一致才能计 whole-run-qualified。中途前缀仅能标 combat-prefix-qualified。

## 试验和判据

单个独立开发输入 NQ4XPILOT000000 用于接口资格，不混入正式先导。正式固定8个新的训练分组种子 NQ4X000000–NQ4X000007，各运行纯 X1 和完整离线教师参照。没有评价种子进入采集/训练，保留全部尝试、未完成搜索、显式回退和失败。

先导用于选择下一项学习方案，本项不训练或更换 X1。扩大整局课程采集的预设门槛：8条教师及8条对照均完整正常规则合格；至少75%实际搜索根获得可执行/公开标签合格的胜利路线；教师至少4局进入第三幕或至少1局真正通关；相对纯X1平均至少+5层且按独立种子配对bootstrap95%下界>0。未通过则报告实际瓶颈，不调门槛/挑最好种子追加。

接口资格修正（正式质量结果产生前）：首轮云端8条对照和8条教师均因本地化路径缺失/未完成选牌载体失败，没有可用质量比较。完整保留experiment失败目录；在experiment2只重试相同8个种子，源修正为明确传入已有本地化目录，并在原版稳定战斗根搜索后capture-only停止。附加end_turn载体仅让驱动到达观察器，搜索和路线执行均不执行载体，不在Env中试占位动作。搜索、资源、种子、门槛及原版比较均不变；不把首轮故障计作死亡/政策收益，不更换种子。

记录总节点/秒数、每幕战斗覆盖、合法/过滤拒绝、每局终点/死亡/胜利/故障、数据大小、CPU/RSS/GPU成本。开发单局900秒、至多64战斗根/10000策略决策；正式总任务3000秒，每局900秒。超限属于试验 truncation，不是原版 death。
