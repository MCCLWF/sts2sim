# 无色牌批次 11：Jackpot

## 目标

移植 Jackpot 的伤害和零费牌生成效果。

## 范围

- 造成 25 点 Move 伤害，升级后 30 点。
- 从玩家角色已解锁单人牌池中筛选基础费用为 0 且非 X 费的牌，再按战斗生成规则过滤。
- 使用战斗卡牌生成 RNG 有放回抽取 3 张；升级后的 Jackpot 升级生成牌，并将生成牌加入手牌。
- 不修改既有通用卡牌生成调用的筛选或 RNG 行为。

## 验收

- 针对性测试验证伤害、升级、生成数量、费用条件、升级传播与手牌落点；Oracle 自定义战斗对拍验证 RNG 和逐状态行为。
- 用生成分发、`test_colorless`、`git diff --check` 和完整 `scripts/check.sh` 验证。
