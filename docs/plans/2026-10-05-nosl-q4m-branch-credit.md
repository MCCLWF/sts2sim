# NoSL Q4-m：局外分支回报的直接学习信号

- 基线：`2220c56`，X1 features 3，A10 正常资源。Q4-l 配对无显著提升，X1 dev 贪心 18.66 层、0/200 胜；同设置继续加长训练不作为本轮方案。
- 目标：回答策略未探索的构筑/休息选择能否通过离线同根分支回报改善。上线仍仅公开观察直接推理。

## 做法和边界

1. 给训练采样 ABI 增加同 batch 槽位 fork，完整复制 Env、actor filter 公开历史、当前合法观察及步数；不添加任何 actor 特权字段，不改变规则。
2. 冻结 X1，采正常 A10 训练种子轨迹；在卡牌选择/休息点的局外决策，从同一实际状态分叉全部合法动作，然后用同一冻结学生贪心跑到真实 terminal。每局最多一个根，按种子划分训练/验证；隐藏 RNG 仅留在训练 Env，种子不进入学习输入。
3. 记录每个动作的原版 terminal、层数、Boss 伤害增量与代价。任何非真实终点/故障明确保留，整根不进入可靠监督标签；未验证的 bootstrap 不填成真实回报。
4. 先做至少 128 个合格根的可行性采样，核对 clone 兄弟独立、同动作复现、动作表不变、分支动作可绑定。采样/学习时限各 900/300 秒，单云实例独立 60 分钟关机保护，取回后确认 shutdown。若没有至少 20% 根的替代动作带来 +0.5 层（或真实胜负提升），不扩大采集/训练，报告阴性。
5. 有潜在收益才采最多 4096 根，训练一个小的局外辅助分支：从 X1 起点，对完整根的动作回报做排序监督，并以原策略 KL 约束共享编码器漂移。训练数据只含公开观察/动作/回报；保留冻结 X1 的战斗观察锚点，控制原战斗策略变化。固定 8 epochs、lr 1e-5、minibatch 128、seed 2，验证 seed 只看泛化诊断，不选大量超参数。

## 预先验收

- ABI fork 的真实选择边界检查：源/多个 clone 当前观察相同；同动作后继、独立改变兄弟与未动源、actor filter 历史与计步合同通过。生成一条分支完整轨迹走正版 oracle 回放，证明新增访问路径，不用自身快照 Hash 冒充原版规则真值。
- 最终学习学生在 NQGRDY 2000 同种子贪心配对中相对 X1平均至少 +0.5 层，95% 配对区间下界 >0、第二幕比例不降低、故障不增加，才称初步有效；有效后 dev200 和至少30条新轨迹原版回放。否则保留 X1、不要增加同设置训练。
- 不将“为每根选最大分支”的特权先知收益算作 NoSL 胜率，不将教师标签拟合率代替整局质量。单学习 seed、固定 tune 集仅支持探索结论，最终 test 未使用。
- 最新 CombatSolver 0.50.0 保持已有离线入口，本实验解决它不覆盖的局外选择；不在未完成学生快照恢复合同前把重造战斗当作同根教师标签。
