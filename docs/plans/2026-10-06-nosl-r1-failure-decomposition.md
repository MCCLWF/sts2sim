# R1：整局失败分解与局外动作价值学习

前置 main `2ab7a89`（Q4-ah 已合入）。分支 `feat/nosl-r1-failure-decomposition`，产物只写 `artifacts/nosl-r1/`。完整高水平 Silent A10、公开历史与 Linux 成品目标不缩小；本项只回答下面登记的问题。

## 为什么换方向

Q4-ac 至 Q4-ah 六轮都在 X1 的战斗头附近做局部改动（结束回合头、动作上下文、更新上限、战术特征权重），全部没有超过 X1。本项不再延续这条线，先回到整局失败的来源。

接手时从 Q4-ah 封存的 X1 评价轨迹（1024 局）重放得到的事实，登记为本项的出发点：

| 事实 | 数值 |
|---|---|
| 死亡位置 | Boss 前 198、第一幕 Boss 481、第二幕途中 295、第二幕 Boss 50；第三幕 0 |
| 休息点 | 回血 3158、升级 0；HP≥80% 时仍回血 1159 次 |
| 有其他路可走时选精英 | 29 / 1911 |
| 卡牌奖励 | 拿 7496、跳过 707 |
| 第一幕 Boss 进场 | HP 62.5、牌组 21.7 张、每场用药水 0.7 瓶；胜 345 / 876 |
| 主动结束回合 | 3 / 239160 个策略决策 |

抽查的 Boss 根牌组是初始 13 张加 5 张左右的普通牌，升级 0–3 次，遗物 3–4 件。

## 要回答的问题

**A（诊断）同一个战斗根上，更好的战斗操作能挽回多少？** 如果连看得见真实未来的搜索也过不了第一幕 Boss，瓶颈在牌组而不在出牌。

**B（学习）冻结 X1 的战斗，只改局外决策，能不能把第一幕 Boss 打过去的比例明显提高？** 这检验“策略停在一个自洽的保守局部最优”这一判断：X1 不升级、不打精英、少打怪，是因为这些动作它早已不再采样，而此前的学习信号（每步层数奖励、GAE λ=0.95）无法把几十到几百个决策之后的收益归到这些动作上。

不在本项范围：战斗策略的再训练、观察 schema 改动、网络结构改动、实机执行器。它们由后续独立工作项根据本项结果决定。

## A：同根对照

新工具 `tools/nosl/nosl_headroom.cpp`：按采样器语义重放一条已记录的策略轨迹，在每场战斗的第一个决策处克隆 Env，由离线战斗者在克隆上打完这一场，原轨迹继续。每场一行：根（幕、层、遭遇、HP、牌组、遗物、药水）、原策略结果、离线战斗者结果。

离线战斗者用现有原生 CombatSolver 移植（beam 30、nodes 10000、软预算 10000 ms，与 Q4-x 相同）。它读真实状态，看得见真实抽牌顺序和敌方未来随机结果；结果只说明“在这一个隐藏世界里更好的操作能得到什么”，不是公开信息玩家的期望，也不是上界证明。不进入任何 NoSL 结果。

输入：Q4-ah 封存评价 `X1.jsonl` 的前 128 局（`NQ4AHEVAL000000–000127`），只读。输出按幕和战斗类型（弱怪、普通、精英、Boss）报告：双方胜率、仅一方获胜的场数、双方都赢时的掉血、每场药水数、搜索耗时与错误数。没有通过门槛；它决定 B 之后的优先级。

## B：局外动作价值学习

### 做法

新模块 `python/nosl/strategy_q.py`。战斗内（公开的 in-combat 标志）始终由冻结的 X1 取最大概率动作；战斗外由局外策略决定。全程每局只从头到尾真实执行一次，不模拟、不搜索、不回滚。

- **采集**：局外行为策略是当前局外策略的贪心动作，并以概率 ε=0.15 换成一个均匀随机的合法动作，使升级、精英、跳过卡牌等动作持续被尝试。每局记录种子、真实终局、动作行号和哪些步是探索。不存观察：一局是种子加动作行号的确定函数。
- **训练**：把记录的局按动作行号重放，再生局外决策的公开观察，回归 `Q(观察, 所取动作)` 到该局的结果目标。重放终点与记录不一致即报错，不当样本。模型结构与 X1 相同，编码器从 X1 权重起步，动作评分头输出层清零后当价值头用。
- **结果目标**（登记的训练信号，不是产品指标）：`层数/50 + 0.5×已通过的幕数 + 2×通关`。相对旧的每步层数奖励，它给“打过 Boss”更高的权重。评价只报告真实结果。
- **使用**：局外取 Q 最大的动作，但只有当它比 X1 自己的动作高出 margin 才替换，否则保留 X1 的动作。margin 在调参种子上从 {0, 0.02, 0.05} 里选目标均值最高的。

与 Q4-y（局外 PPO，两个种子各 4096 局）的区别：探索是强制的、不会塌缩；用全部样本做价值回归而不是按策略梯度；目标对过 Boss 敏感；规模是它的二十多倍。

### 预算与数据划分

本机 CPU 6 个采样进程加本机 GPU（fp32 推理），一次只跑一个任务，不开云。

| 步骤 | 种子 | 规模 |
|---|---|---|
| G0 采集（基础策略 X1，ε=0.15） | `NR1G0T000000–099999` | 100000 局 |
| Q0 训练 | G0，每 20 局留 1 局作验证 | 2 轮，batch 1024，lr 2e-4 |
| 调参评价 | `NR1TUNE000000–000511` | X1 与 Q0 的三个 margin，各 512 局 |
| G1 采集（基础策略 = 选中的 Q0 规则，ε=0.15） | `NR1G1T000000–099999` | 100000 局 |
| Q1 训练 | 从 Q0 继续，只用 G1 | 2 轮 |
| 调参评价 | 同上 512 个调参种子 | Q1 的三个 margin |
| 本项留出评价 | `NR1EVAL000000–001023` | X1 与最终选中的规则，各 1024 局 |

训练轮数只按留出验证局决定：第 2 轮的验证 Q 均方误差若比第 1 轮仍下降超过 1%，追加第 3 轮，最多 3 轮；不看调参或留出评价结果来定轮数。

训练、调参、留出种子前缀互不相同。项目级最终测试集 `NOSLTEST` 不使用。留出评价只在全部训练和选择结束后跑一次，不按其结果追加种子、挑权重或改判据。学习器种子本项只有一个；跨初始化的稳定性在出现正向结果后另行登记。

预计墙钟：每代采集约 1 小时、训练约 40 分钟，合计 4 小时以内。若采集或训练明显超出（任一步超过 3 小时）先停下查吞吐，不默默延长。

### 判据（先于结果登记）

主要量：进入第二幕的比例（即打过第一幕 Boss），以及完整通关数。同种子配对比较，10000 次 bootstrap 的 95% 区间。

- **继续**：留出集上，最终规则进入第二幕的比例比 X1 至少高 8 个百分点，且配对差的 95% 下界大于 0。满足则扩大同一方法（更多代、更多数据、第二个学习器种子），并登记战斗策略在新牌组分布上的再训练。
- **不继续**：G1 之后调参集上进入第二幕的比例没有比 X1 高出 4 个百分点。这说明在 X1 的战斗水平下，局外价值学习在这个预算内拿不到收益；下一步改为先处理战斗（A 的结果决定是教师蒸馏还是局部目标强化学习），不靠加数据重复本项。
- 介于两者之间：再跑一代（G2，同样预算）后按同样判据判定一次，之后不再追加。

无论哪种结果都报告全部尝试、真实通关、死亡、截断与故障；0 通关不称高水平。平均层数只作参考。

验证信号（不作通过条件）：留出局上 Q 的解释方差；探索步上预测优势与实际优势的相关；各类局外决策被替换的次数；替换后的行为统计（升级次数、精英次数、卡牌选择）。

### 保真

本项不改 Env、规则、观察 schema、X1 权重和 actor filter。最终选中规则的留出轨迹按 Q4 惯例抽取（前 2 局、最深终局、全部通关局）做正常 TestMode=false 的正版回放，比较合法动作、逐步快照和 end.run。

## “高水平”的验收标准（提议，待用户确认）

产品指标只有一个：正常资源、未见种子上的完整 A10 通关率（含第二个最终 Boss，以正版终局为准）。

| 档 | 条件 |
|---|---|
| 存在性 | 至少 2000 个未见种子上通关率的 Wilson 95% 下界大于 0，通关局全部通过正版回放 |
| 可用 | 通关率 ≥ 20% |
| 高水平 | ≥ 1000 个未见种子上通关率 ≥ 50% 且 Wilson 95% 下界 ≥ 45%；至少 3 个训练初始化各自 ≥ 40%；Linux 实机完整局的通关率与模拟器评价统计相容 |

50% 这个数是参照前作高进阶下熟练玩家的水平定的，没有本作 A10 的公开人类统计作依据；如果用户有自己的参照（例如本人或社区的 A10 猎手胜率），以它为准。
