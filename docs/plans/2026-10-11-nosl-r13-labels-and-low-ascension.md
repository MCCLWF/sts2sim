# R13：标签继续放大；低进阶另用一套守卫

前置：main `63e1ba2`（R12 已合入）。分支 `feat/nosl-r13-labels-and-low-ascension`，产物只写 `artifacts/nosl-r13/`。完整高水平 Silent A10、公开历史与 Linux 成品目标不缩小；部署只做策略推理。全程本机，无人值守（服务 `nosl-r13`，看门狗 `nosl-r13-guard`）。用户 2026-10-11 同意按这两条继续。

## 依据

- R11 被重启打断：标签 54.5 万 → 96.7 万，留出解释方差 0.09 → 0.123，整局上对 R10 规则的增量 +0.008（下界 −0.0003），“标签加倍有没有可测的增量”没有答完。R11 那批新局还剩 19 段没标。
- R10、R12 三次看到同一件事：留药水、先删牌、多升级在进阶 10 更差、在进阶 0 更好（R12：留药水 +0.02 到 +0.03，先删牌进第三幕 +5 个百分点；R10：血近满就升级 +0.028）。这些都只是 2048 局的旁证，没有留出确认，也不能按进阶切换。

## 问题

1. 标签到约 140 万时，规则在整局上对现在的组合有没有可测的增量？
2. 低进阶换一套守卫，进阶 0 / 5 的结果和通关率提高多少？界线放在哪？

## 做法

代码改动（默认行为不变）：守卫加 `smith=X`（休息点 HP ≥ X 就升级）；Python 的 `--guards-low LEVEL:守卫` 与策略包的 `guards_low LEVEL 守卫`（该进阶及以下的局改用这一套），原生 actor 同步。冒烟：带着低进阶那一套跑进阶 10，256 局与 R12 的组合逐局相同；进阶 0 各守卫都触发。

参照 `ref` = 现在的成品候选：R5 的最终组合 + R10 的战斗规则（`m40b`，margin 0.05）+ 三条纠错守卫。

**C 路（标签）**：R11 的局表里第 5500–14999 局，19 段，设置同 R8 / R11。

**G 路（进阶 10，调参集 `NR13TUNE` 4096 局，都带三条纠错守卫）**：`ref`；`s2`（R11 第二期两个拟合的平均，87.4 万标签）margin 0.05、0.02；每多 8 段新标签一期（`s3`、`s4`，最后不满 8 段的也做一期）：全部标签上拟合两次（24 轮、1e-3、余弦、保留留出最好的一轮），平均后 margin 0.05、0.02 各一臂。

**L 路（低进阶）**：进阶 0 调参集 `NR13ZTUNE`（4096 局）上，`ref` 之外各加一条：`hold=0.5`、`hold=0.3`、`removefirst`、`smith=0.9`、`nopotionbuy`。按判据拼出低进阶那一套，然后在进阶 0、进阶 5（`NR13FTUNE`，4096 局）的调参集上各评一次，再在留出集上与 `ref` 各跑一次：进阶 0 `NR13ZEVAL` 8192 局（通关率低，要大样本），进阶 5 `NR13FEVAL` 4096 局。

## 种子

`NR13TUNE`、`NR13EVAL`（进阶 10）；`NR13ZTUNE`、`NR13ZEVAL`（进阶 0）；`NR13FTUNE`、`NR13FEVAL`（进阶 5）。都没有用过。

## 判据（先于结果登记）

- **问题一**：规则臂对 `ref` 在 `NR13TUNE` 上结果目标配对差 ≥ +0.005 且 95% 下界 > 0（同 R11）；满足的取最大者，在 `NR13EVAL` 上与 `ref` 各跑一次，留出上下界 > 0 才算确认。都不满足则留出不动，结论写“到 140 万标签仍没有可测的增量”或如实写跑到了多少。
- **问题二**：某条守卫在进阶 0 调参集上配对差 ≥ +0.01 且下界 > 0 才进低进阶那一套（`hold` 两档取好的）。**确认**：进阶 0 留出集上结果目标配对差的下界 > 0。界线：进阶 5 留出集上下界也 > 0 则 `guards_low 5`，否则 `guards_low 0`；进阶 1–4、6–9 没有测，前者按 0–5 的区间内插使用，后者不用。通关数与其区间一并报告，它是低进阶上唯一直接的指标，但 8192 局里也只有几十局，不单独作判据。
- 低进阶的结果单独标注，不算进阶 10 的成绩。全部尝试、通关、死亡、截断、故障都报告。
