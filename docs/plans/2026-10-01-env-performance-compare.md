# Env 性能大测试：sts2sim / sts2-ai

目标：在冻结源码和同机 Release 条件下，测量现有环境完成同类操作的实际成本，找出吞吐、克隆、接口和追踪的瓶颈。本项属于 M5 性能测量，不升级完整 Env/RF 或保真验收资格。

前置：sts2sim b5ad9d5，sts2-ai <私有提交>；独立工作树冻结，原项目删除 CLAUDE.md 的用户改动不纳入执行代码。两项目基线 v0.111.0；已有普通 Env 和 CombatState API。

任务与预算：

1. 在 tools/bench/compare 下保存可复现 C++、C# 与 Python 驱动；不修改任一模拟器规则或对方项目源文件。
2. 五角色 × A0/A10 × 三幕代表遭遇 × 三个固定 seed × 首/第三回合，180 个根；先比较共同状态投影及 EndTurn/普通出牌后继。不同投影独立登记，不混入有效配对排名。
3. 核心测量每项预热至少 128 次，7 组 × 64 次，3 次独立进程交替顺序，固定同一 P 核；报告分位数、配对耗时比、失败数、C# 分配/GC 与进程 RSS。极短操作扩大循环数。
4. 单列公共 Predict/Hash/Observe/trace、Python ctypes 的开销；C# gRPC 带自动战斗搜索，单列产品工作负载和 Echo 通信，不能与逐动作 Env Step 直接排名。
5. 对有效代表根测 1/2/4/8 工作线程吞吐（相同总任务、报告实际 CPU 亲和性与 GC），区分固定状态吞吐和自然整局吞吐。
6. 检查基准自校验、退出码、根未变、重复后继稳定性；测量工具不进 CTest。既有接口相关 CTest 定向执行一次。没有引擎行为修改，不重复完整差分门禁。
7. 保存原始 JSONL、源码/二进制 SHA256、硬件/负载/配置和报告；README/路线图仅新增本次有限测量入口。不提交大产物、不发布外部仓库。

涉及文件：tools/bench/compare/*、CMakeLists.txt（独立目标）、docs/reports/2026-10-01-env-performance-compare.md、docs/roadmap.md、README.md。

验收：180 根全部尝试且每个失败可追溯；有效配对按共同输入/动作/投影认定；全部统计可以从保存的原始记录重建；不把 C++/C# 的复制范围、不同观测编码或带搜索的 gRPC 结果解释为语言本身的速度差异。若某指标受接口限制，明确记录未执行或不可比较。
