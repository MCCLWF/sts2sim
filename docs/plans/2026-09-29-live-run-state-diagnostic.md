# 游戏内整局状态诊断

分支：`feat/live-run-state-diagnostic`。延续游戏内战斗对拍桥，先确定正常开局与 Env 的首个整局状态是否一致，供连续地图/事件动作桥接使用。

1. 通过 C ABI 导出已有的 OracleRun.DumpRun 格式，提供按角色名称启动 Env 的入口。
2. 在真实游戏正常开局的静止边界抓取同格式 run 状态，逐路径比较并保留游戏、Env 原值；此阶段诊断差异，不把尚未验证的 run 状态作为战斗动作成功的证据。
3. 在隔离正版游戏进程中测试全解锁及实际档案开局，记录首个差异；编译和仓库门槛验证。发现原版语义缺口时登记，不通过覆写 RNG 修补。
