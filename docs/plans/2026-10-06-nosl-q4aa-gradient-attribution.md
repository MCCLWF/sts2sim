# Q4-aa：冻结首轮战斗样本的更新分解

基线main e617a6a。Q4-z四臂均低于X1，首更新approx_kl .065–.091；新遭遇标签对旧value误差较大，但没有因果证据。历史Q4-f讨论过critic与熵，不能把不同回报/批次的旧结论当本批首因。本项用实际冻结训练样本，分解PPO策略、价值和熵的更新影响，再决定下一项稳定学习实验；高水平Silent A10整局/Linux NoSL目标不变。

- 原版v0.111.0、全解锁正常Silent A10，公开schema/features3/filter1、正式X1 SHA 6fb5f1955a11d55175d348659460ce459017baa018f7cf9242a671ba19266703不变。
- 只用Q4-z学习seed1/3的C/R首批各32条已冻结实际训练历史；C/R除了标签以外完全相同。逐动作重放原生Env，核对inside/action-kind/HP前后、完整动作数及真实终点，重建全部战斗多合法选择的四表。原始标签独立公式重新核对，不改奖励、不补种子、不用评价集。
- CPU float32重算旧X1 logp/value，规范256批次；这些不是原CUDA采样浮点数的逐位复现。原始轨迹固定、不重新采样动作，actor仍只读公开四表。诊断不运行教师搜索、未来分支或实机动作。
- 旧Q4-v/w/x/y/z冻结数据保持不变，所有新增输出只写artifacts/nosl-q4aa。用户云实例保持shutdown，本项不启动云GPU。

## 固定分解与消融

四个队列C1/R1/C3/R3，分别从新X1和fresh Adam出发：

| 更新臂 | 策略P | 价值V | 熵H |
|---|---|---|---|
| P | 是 | 否 | 否 |
| PV | 是 | 是 | 否 |
| PH | 是 | 否 | 是 |
| PVH | 是 | 是 | 是 |

P为既有clipped PPO、全首批标准化实际MC优势；V系数.5（MSE先乘.5），H系数.05。全部lr.000133、clip.2、2epochs、minibatch256、grad norm.5，四臂使用相同seed置乱。旧value与优势固定，不按更新后value重新计算。原更新函数的KL自适应只影响下一轮；此处仅一轮，另记录真实梯度/优化步数。

1. 在全部首批行上按样本数加权累计初始P/V/H梯度，报告全参数及shared/policy-head/value-head范数、余弦及组合范数；不只挑高梯度状态。
2. 每队列额外运行未修改的episodic_strategy.update，与PVH最终参数摘要严格相同，否则消融不合格，先查诊断实现。
3. 每臂完成一轮后，在同一全部公开样本上测精确KL(old||new)、熵、argmax变化比例、clip fraction、样本动作logp变化、value RMSE及有限值/合法mask，保存诊断权重。初始同模型测量KL约零、0动作变化。
4. 仅描述这两个冻结首批内的损失干预效果。不是新正常整局强度评价，不按本项挑正式模型，不把低KL当高水平验收。新配置必须另登记匹配的新正常整局训练与评价。

## 判读与预算

若两seed的某信用类型中，加入V在含/不含H两种配对下都使最终KL增加至少.005且至少1.5倍，记录该信用的价值耦合信号；H用同样的双配对规则。只有两信用均通过才称本项共同信号。多个信号保留，不从其中事后删掉失败对照；若没有复现则先检查P更新跨度/样本优势噪声。梯度范数不能单独证明策略退步首因，Adam与裁剪具有非线性；完整整局改善仍待后续实验。
