# NoSL Q4-i：把“这条路上最少要打几个精英”给策略

- 日期：2026-10-05。分支：`feat/nosl-q4i-route-feature`。
- 上级需求：[Silent A10 整局 NoSL 计划](2026-10-03-silent-a10-nosl.md) I01（输入是公开信息）、§11 的 Q4；用户要求先确认训练在稳步前进。
- 前置：[Q4-g](../reports/2026-10-05-nosl-q4g-kf-continuation.md)（KF 停在贪心约 16.3 层）、[Q4-h](../reports/2026-10-05-nosl-q4h-kf-imitation.md)。
- 本计划写于任何带路线特征的训练之前；“已经知道的”一节是对现有 KF 策略的测量。

## 已经知道的

**约三成的局死在第一幕的精英战里，而这些精英战几乎都不是策略在岔路口选的。** KF 两个种子的 dev 轨迹（各 200 局，按分布采样）：

| | KF 种子 1 | KF 种子 2 |
|---|---:|---:|
| 第一幕精英战场数 | 150 | 143 |
| 死在这些精英战里的局 | 57 | 63 |
| 岔路口上精英与别的路并列的次数 / 选了精英 | 241 / 8 | 241 / 0 |
| 所有选项都是精英的次数 | 1 | 0 |

策略在岔路口总是避开精英，却仍然每局打 0.7 场：精英是几步之前选的那条路上唯一的后继，走到那里时已经没有别的路（唯一动作由采样器自动执行，不算决策）。
地图整张都在屏幕上；观察里每个可去的节点带着“后面一共有几个精英”这样的合计，没有“走哪条路最少碰到几个”。

**按路线规划来走值多少**（`tools/nosl/override_eval.py --avoid-elites`，KF 种子 2 的 3,000 万检查点，2,000 个配对种子，贪心）：
在地图上改选“从它出发到本幕终点、路上精英最少”的节点，并列时听策略的，其余不动。

| | 原样 | 按路线走 | 差（标准误） |
|---|---:|---:|---|
| 平均层数 | 16.55 | 17.91 | +1.36（0.13） |
| 进入第二幕 | 24.1% | 29.9% | |

这是到目前为止所有脚本替换里最大的一处（升级 +0.14，留药水 −1.29）。

## 问题

把这个量作为输入给策略，它自己学不学得会这样走，水平跟不跟着上去？

## 改动

模型输入的第 3 档（`--features 3`，在第 2 档之上）：地图决策时，对每个可去的节点算出“从它到本幕终点的任意一条路上最少有几个精英（含它自己）”，
以及它比当前最好的选项多几个；两个数经一层线性变换加到这个节点的 token 上。算法是在屏幕上的地图节点（列、行、类型、下一行的后继）上从后往前做一遍最短路，
全部来自现有观察，**观察的格式不变**，采样器、过滤器、实机 Mod 的编码都不用动。它是对公开地图的算术，不模拟游戏，也不试动作。

部署用的原生前向（`nosl/policy_net.cpp`）还没有这一档，`nosl.export` 对第 3 档的模型会报错；这个臂的评价全部走 Python 模型。
值得保留的话，原生前向要补上同一遍最短路并做数值对照，才能上实机。

## 设置

**KFR = KF + `--features 3`**，从零，种子 1，2,000 万决策。其余与 KF 完全相同。一次一个训练、6 个采样进程。

## 判据（结果出来前固定）

贪心快照，同一批 2,000 个固定种子（`NQGRDY…`）。KF 在 2,000 万时是 16.46 和 15.91 层（平均 16.18），之后停在 16.0–16.6。

- **有没有用**：KFR 在 2,000 万的贪心平均层数 ≥ 17.2（KF 两个种子的平均加 1.0）。满足才跑种子 2。
- **稳步前进**：仍是那三条，用 KFR 自己 1,000 万、1,500 万、2,000 万三个快照：≥ 1.0 层、≥ 0.3 层、进入第二幕 ≥ 5% 且在涨。两个种子都满足才写“稳步前进”。
- **机制**：贪心评价里每局第一幕精英战的场数（KF 约 0.7）；对 KFR 的最终检查点再做一次 `--avoid-elites` 配对替换，替换带来的差应当接近 0。

## 预算

一个运行约 66 分钟，快照评价和替换各约 5 分钟。不调参。

## 追加（2026-10-05 04:40，KFR 种子 1 的结果之后、下面这个运行之前）

**KFR 种子 1**：贪心 16.22 / 16.57 / 16.68 层（1,000 万 / 1,500 万 / 2,000 万），每局第一幕精英战 0.51 → 0.39 → 0.32 场（KF 种子 2 是 0.85）。
“有用”（≥ 17.2）不满足，稳步前进的第 1、2 条不满足（+0.46、+0.11），不跑种子 2。机制是成立的：策略学会了绕开精英，
但走到 Boss 的局变多（64%）、打赢的变少（约 17%，KF 约 30%）——少打精英就少拿遗物。

脚本替换在 KF 种子 2 上给的是 17.91 层：那个策略的牌组和打法是在“每局打 0.85 场精英”的条件下练出来的，Boss 胜率三成，只把路线换掉。
KFR 从零带着路线特征训练，到 2,000 万时 Boss 战打掉的比例还只有 0.70（KF 是 0.72–0.75）。

**再测一个臂：KFR-w = 在 KF 种子 2 的 3,000 万检查点上接上路线特征**（新输入层从零起步，输出不变），其余同 KF，接着训练 1,000 万决策。
它问的是：已经会打 Boss 的策略，给了路线信息之后能不能学到脚本替换的那个水平，并且接着涨。

判据（贪心快照，同一批 2,000 个种子；起点是 KF 种子 2 在 3,000 万的 16.56 层、22.7% 进第二幕、每局 0.85 场精英）：

- 有没有用：4,000 万时 ≥ 17.56 层（起点加 1.0；脚本替换是 17.91）。
- 稳步前进（这条线上）：4,000 万 − 3,000 万 ≥ 1.0 层；4,000 万 − 3,500 万 ≥ 0.3 层；4,000 万时进入第二幕高于 22.7%。
  它只有一个种子、一条线，满足也只能写“这一条线上满足”，不能写“稳步前进”。
- 机制：每局第一幕精英战的场数降到 0.4 以下。
