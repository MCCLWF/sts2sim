# 游戏进程内 Env 对拍

日期：2026-09-29。分支：`feat/live-game-env-diff`。对应通用 Env 完成路线 E1/E4 的真实游戏捕获桥与差分门禁。

目标：在正版 v0.111.0 游戏进程中加载独立 C# Mod，捕获实际战斗根和玩家动作，在同一进程把动作送入 C++ Env 的 owned 后继，并记录游戏与 Env 的逐字段差异。游戏仍执行原本动作；本工具不控制搜索或 UI。

任务：

1. 使用游戏 `ActionExecutor`/`CombatManager` 事件捕获稳定边界，输出 seed、遭遇、角色、升阶、动作、游戏状态和 Env 状态。
2. 只有根状态一致时才能向 Env 发送动作；动作失败、选择点或未移植内容需要明确记录，不能把后续比较当作成功。
3. 在隔离的正版游戏副本中实际加载 Mod、执行至少一个玩家动作，保留本机原始日志并写验收报告。
4. 逐步扩大到普通整局各决策类型、选择、实际档案和完整快照/RNG 比较；当前结构投影只是首批链路，不代表“逐位一致”。

验收：编译、游戏加载日志、实际动作记录与 Env transition 记录；比较字段和缺失边界必须在报告中列明。合入 main 前运行完整 `scripts/check.sh`。
