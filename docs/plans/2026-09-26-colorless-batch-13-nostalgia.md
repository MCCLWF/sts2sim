# 无色牌批次 13：Nostalgia

## 目标

移植 Nostalgia 与“本回合前一张攻击/技能牌回到抽牌堆顶”的效果。

## 范围

- Nostalgia：1 费 Power，升级后 0 费，给予 1 层 `NOSTALGIA_POWER`。
- 在 POD 战斗状态中统计本回合已开始打出的攻击/技能牌次数。
- 结果牌堆修改发生在 `CardPlayStarted` 之前，因此 Nostalgia 检查此前计数；前 `Amount` 张攻击/技能牌若原本将进入弃牌堆，则改放抽牌堆顶。
- 仅在普通玩家回合开始时清零；额外回合沿用同一历史计数，与游戏历史条目语义一致。

## 验收

- 测试升级费用、第一张攻击/技能牌回抽牌堆顶，后续牌进入弃牌堆。
- Oracle 自定义战斗牌组逐状态对拍，并运行完整 `scripts/check.sh`。
