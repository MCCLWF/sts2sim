# R5 原生推理与交互式游戏控制面板

用户要求：导出 R5；正常启动 Linux 游戏并进入猎手对局后，Mod 自动推理和操作。提供可拖动、可折叠的控制与信息面板。运行时不依赖 Python。

基线：main 0ca49e8；分支 feat/nosl-r5-interactive-mod。沿用 v0.111.0、单人 Silent、公开观察、CPU 原生推理。用户现有 README/roadmap 改动、CLAUDE.md 删除与性能报告不属于本项。

## 实现

1. 重新导出 R5 完整组合：combat-01690、X1、f3c、table-g4、chain-g5；与已验收 bundle 的权重及规则哈希核对。
2. 保留隔离 autorun 诊断入口，新增正常启动模式：检测真实对局、仅接管 Silent 单人，读取实际游戏观察，不创建模拟器、不更改种子/档案/解锁/游戏速度。
3. 控制面板：标题栏拖动、收起/展开、开始/暂停/继续、交还手动、自动接管开关；按用户补充要求不显示楼层和生命，显示模型、当前决策、推理路径、候选数、动作/推理数量、最近动作、最近/平均耗时与错误。位置、收起和自动接管偏好本地保存。F8 暂停/继续，F9 交还。
4. 生命周期：退出对局取消驱动；重新开局可重新接管；暂停/交还在当前动作及嵌套选择完成后生效，移除选牌接管，恢复手动输入；原生加载失败时面板提示，游戏保持可用。
5. 包含模型的可安装目录与压缩包；在本机游戏 mods 中部署，保留已有其他 Mod。
