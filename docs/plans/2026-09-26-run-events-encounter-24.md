# M4 run 内容批次 24：蘑菇事件与 Construct Menagerie

## 目标

继续补齐可由铁甲战士进入的 run 级内容：Hungry for Mushrooms 事件及其奖励遗物，以及第三幕 Construct Menagerie 普通遭遇。

## 工作项

- Big Mushroom：获得时增加 20 最大生命；持有者第一回合少抽 2 张牌。
- Fragrant Mushroom：获得时失去 15 生命，并随机升级牌组中最多 2 张可升级牌。
- Hungry for Mushrooms：提供两项遗物选择；选择 Fragrant Mushroom 的选项带 15 点伤害预警。
- Construct Menagerie Normal：按源码生成 Punch Construct、Cubex Construct、Cubex Construct。
- 添加事件/遗物/遭遇行为测试和 Oracle L3 遭遇对拍，运行完整检查。

## 边界

不扩展其他角色卡牌；需要未移植怪物或事件行为的路径继续保持 `Unported`。
