# M3 环境层与战士范围收口

分支：`feat/m3-environment`。M2 已验收；本阶段暂停其他角色的继续扩充，集中于铁甲战士、通用 run 内容与 M3 环境 API。

## 目标

1. 为现有纯数据 `Env` 增加合法动作枚举、稳定观测编码、整局克隆、哈希和 determinize。保留选择前缀重放语义。
2. 用单元测试验证 reset、clone/hash、合法动作和确定化的可重复性；不泄漏 RNG 计数器或未公开的未来队列到观测。
3. 盘点战士在战斗中可能获得的其他角色牌，并明确列为当前未实现边界，不把它们误报为战士完成。
4. 继续补齐战士专属卡牌、Power、通用遗物/药水和 run 级路径，按 Oracle L3/L4 逐批验收。

## M3 验收

- `Env::LegalActions` 覆盖地图、战斗、奖励、事件、休息点、商店、宝箱和嵌套 Choice。
- `Env::Clone` 不共享状态；`Hash` 对相同决策点稳定、对状态变化敏感；`Determinize` 保持可见状态并只打乱隐藏抽牌顺序。
- 观测编码只包含当前决策可见的运行/战斗字段，不包含 RNG 状态、未来房间队列或完整牌堆身份。
- `ctest`、M3 专用测试和 `scripts/check.sh` 通过。
