# 计划：第一幕事件（M2）

执行者：Codex（luna）。分支：`feat/act1-events`（基于 `feat/run-skeleton`）。审阅与合入：Claude。

## 背景

- 事件框架已经就绪：`game/Models/EventModel.{h,cpp}`、`game/Events/EventOption.{h,cpp}`，样板是 `game/Models/Events/Neow.h`（先古事件）。
- 整局对拍 L4（`tests/l4/l4_run.py`）已能跑到第一幕 Boss 前；不带 Neow 的 64 局里，停下的原因大半是事件：
  - `Events.X.IsAllowed is not ported`：拉下一个事件时，事件池里每个候选都要问 `IsAllowed`；
  - `Events.X.CalculateVars / GenerateInitialOptions is not ported`：进入了该事件。
- 已有的命令：`CardSelectCmd`（选牌）、`RewardsCmd.OfferCustom`（事件里的奖励界面，嵌套选择）、`RelicCmd.Obtain`、`PotionCmd.TryToProcure`、`PlayerCmd.GainGold/LoseGold`、`CreatureCmd.Heal/GainMaxHp/LoseMaxHp/Damage`、`CardPileCmd.Add/RemoveFromDeck`、`CardCmd.Upgrade`。

## 任务

1. **所有能在第一幕出现的事件的 `IsAllowed`**（Overgrowth、Underdocks 两个第一幕的事件池，加上共享事件池；从 `Models/Acts/*.cs` 和 `ActModel` 找全），做成部分移植：
   - 只移植 `IsAllowed`（以及它调用的成员），类头部加 `// Members left to Unported (tools/port/refresh_not_ported.py):` 标记行，运行 `python3 tools/port/refresh_not_ported.py` 生成 `SIM_NOT_PORTED` 列表。样板见 `game/Models/Relics/LuckyFysh.h`。
   - 这一步完成后先提交一次。
2. **事件本体**：按 L4 里出现的频率从高到低，逐个完整移植事件（`CalculateVars`、`GenerateInitialOptions`、各选项的回调、页面切换、`SetEventFinished` 等），逐行照 C#。选项回调用 `SIM_OPTION` / `register_event_option_fn`，参照 `Neow.h` 和 `EventModel.cpp`。
   - 需要框架里没有的大机制时**跳过这个事件**并在报告里写明卡在哪个 C# 方法上：变牌（`CardCmd.Transform*`）、附魔（`CardCmd.Enchant`）、事件内战斗（`EnterCombat…`/`GenerateInternalCombatState`）、先古（Ancient）事件。
   - 缺一个简单的、C# 里有的重载或方法，可以逐行照 C# 补上，在报告里单列。
3. 每移植完一个事件就提交：`feat: port event <类名>`。
