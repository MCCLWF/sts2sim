# 计划

每项工作一份计划，文件名 `YYYY-MM-DD-<里程碑编号>-<名称>.md`，例如 `2026-09-25-m1b-oracle-combat.md`。

计划至少写清：

1. **目标**：对应路线图里的哪一项，做完以后能验证什么。
2. **前置条件**：依赖哪些已完成的工作，实际状态如何。
3. **任务**：按顺序列出，每个任务写涉及的文件。
4. **验收**：用什么命令、以什么结果为准。优先用差分对拍，不要手写期望值。
5. **不做什么**：明确排除的范围，防止范围膨胀。

执行完成后在 `docs/reports/` 写执行报告，并更新 `docs/roadmap.md`。
