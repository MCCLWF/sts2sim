# NoSL Q4-a：零代价循环与丢药水——actor 过滤器 v1

- 日期：2026-10-03。分支：`feat/nosl-q4a-actor-filter`。基线：main `425f052`。
- 上级需求：[Silent A10 整局 NoSL 计划](2026-10-03-silent-a10-nosl.md) §11 的 Q4（整局组织与信用分配）中的一个子问题，
  以及 R02（实机连续操作）。
- 前置：[Q2 报告](../reports/2026-10-03-nosl-q2-learning-loop.md)。

## 问题

Q2 的策略在不改变公开状态的动作上空转：同一个卡牌奖励反复打开又跳过（200 局 3,261 次跳过），
商店里反复开始又取消同一项（一局 3 万步直到被截断），战斗外丢掉 211 瓶药水。
这浪费采样，也会让实机策略卡在一个界面上。

**问题**：只用公开观察和已做过的动作，把这些动作从 actor 的动作表里拿掉，会不会让结果变差？能不能消除空转？

**假设**：不会变差，空转消失。风险：规则拿掉了本来有用的动作（比如跳过后想回头再拿牌）。

## 最小改动

`nosl/actor_filter.{h,cpp}`，过滤器 v1。它是策略侧的规则，不是游戏规则：Env 仍然接受被拿掉的动作。

1. 某个动作做完后回到了**完全相同的观察**（打开卡牌奖励后跳过、开始删牌后取消），同一层再遇到这个观察时不再提供该动作。
2. 丢药水只在药水栏全满时提供。
3. 不会拿掉最后一个动作；剩下唯一动作时照常自动执行。

过滤器只读观察表和已做过的动作，不读隐藏状态、不模拟。采样器、轨迹转脚本工具用同一份实现；
检查点记录过滤器版本，评价时按检查点的版本运行。过滤器版本 0（无过滤）必须与 Q2 的行为逐动作相同。

这是一条手写的可观察规则。按上级计划 G2，它要明确记录、单独评价，不能混在“学出来的策略”里不提。

## 固定的实验设置

- 两个臂，其余设置与 Q2 完全相同（环境、奖励 `floor-v1`、模型、PPO 超参、2,000 万决策、480 并行局）：
  - A：过滤器 0。直接用 Q2 的两个运行（学习器种子 1、2），不重跑。
  - F：过滤器 1。学习器种子 1、2 各一个新运行。
- 评价：`NOSLDEV0000`–`0199`，按策略分布采样，`--policy-seed 1`，8 个采样进程。

## 预算

F 臂两个运行各 2,000 万决策，单个运行墙钟上限 2 小时。不调参；实现缺陷修复后 F 臂整体重跑并写明。

## 先行检查（跑实验之前必须通过）

1. 过滤器 0 等价性：用新代码把 Q2 的 400 条 dev 轨迹重新转成脚本，与 Q2 当时生成的脚本逐字节相同。
2. 过滤器 1 的 20 局随机策略冒烟：无错误；丢药水只出现在药水栏满时；同一层内不出现“同一观察、同一动作”第二次。

## 判据（结果出来前固定）

统计单位是整局，区间为自助法 95%。

1. **空转消除**：F 的两个种子在 dev 上都没有步数上限或挂起的局。
2. **不变差**：对每个学习器种子，F 的 dev 平均层数区间不整体低于同种子 A 的区间（即 F 的区间上界 ≥ A 的区间下界）。
3. 1 和 2 都满足则采用过滤器 v1 作为后续实验的默认；否则不采用，并报告是哪条规则造成的。
4. 同时报告：每局策略决策数、卡牌奖励“拿/跳过”次数、战斗内外的药水使用与丢弃次数、进入第二幕的局数与胜利数、训练失败计数、
   F 的 dev 轨迹经正版回放的结果。
5. 即使 F 的层数更高，也只说“没有变差/更高”，不把它归因于某一条规则——两条规则是一起上的。
