# R5：过 Boss 的把握作为局外决策的依据

前置：main `bfdd338`（R4 已合入）。分支 `feat/nosl-r5-style-and-boss-readiness`，产物只写 `artifacts/nosl-r5/`。完整高水平 Silent A10、公开历史与 Linux 成品目标不缩小。全程本机，不使用云。

2026-10-08 用户要求：继续开发，按 R4 报告里说的下一步做。

## 依据

R4 的结论（[报告](../reports/2026-10-08-nosl-r4-alternating-scale-up.md)）：墙在“带进 Boss 战的东西”上；同一副牌、同一个开局下操作的余地有限；局外这一层一次只改一个决策、拿整局结果当信号的方法（随机对照、表、价值网络的一步替换）已经量不出进一步的好处。整局结果的噪声（标准差约 0.45）比一张牌的效果（约 0.02）大二十倍。

登记本项之前做的分析，只用 R4 的采集数据（G3–G5，约 30 万局，进阶 0/5/10 混合，带 ε 探索），不涉及任何调参或留出种子：

**每一局走到 Boss 门口时的状态和过没过，数据里都有。** 取每局在 Boss 前一层（休息点）最后一个记录下来的局外决策时的状态（牌组、遗物、药水、HP；最后一步选回血的把 HP 加上三成），以及这一局有没有进下一幕。共 298057 个“门口”：

| | 门口数 | 过 Boss 的比例 |
|---|---:|---:|
| 第一幕 Boss，进阶 0 / 5 / 10 | 72973 / 68066 / 109115 | 81.5% / 75.4% / 45.6% |
| 第二幕 Boss，进阶 0 / 5 / 10 | 25677 / 15928 / 6298 | 12.5% / 12.3% / 4.5% |

**过不过 Boss 可以从门口的状态预测得很准，而且信号比整局结果干净得多。** 逻辑回归（特征：进阶、哪个 Boss、HP 比例、最大 HP、药水数、每张牌有几张 / 升级了几张、每件遗物、常见牌和遗物与 Boss 的交互），在 G3、G4 上拟合，在 G5 上检验：

| | 第一幕 Boss | 第二幕 Boss |
|---|---:|---:|
| 检验集 AUC（只用汇总特征 / 加每张牌和遗物 / 再加与 Boss 的交互） | 0.843 / 0.910 / 0.921 | 0.796 / 0.858 / 0.868 |
| 进阶 10 检验门口里，预测把握最高的 20% / 10% / 5% 实际过 Boss 的比例（不带交互的那个模型） | 92.8% / 96.8% / 97.6% | 19.4% / 29.7% / 36.2% |

- 第一幕 Boss：进阶 10 的门口平均只过 45.6%，但**数据里本来就有一批能稳过的门口，模型认得出来**。它们的共同点：毒的成长牌（毒雾、爆发、弹跳药瓶、致命毒药、蛇咬，尤其是升级过的）、几件遗物、门口 HP 高、手里留着药水、升级牌多。系数的量级（对数几率）：HP 每多一成 +0.55；每瓶药水 +0.59；每张升级牌 +0.22；毒雾 +1.5，升级后 +2.2。
- 第二幕 Boss：最好的 5% 门口也只过三成多。升级数、删没删基础牌在现有数据里几乎不影响（每张升级 +0.05）——现有数据里没有“升级很多、删得很干净”的牌组，模型对那一片没有依据。
- 进阶 10 的局有四成死在第一幕 Boss（R4 的死亡分解），进了第二幕的又有六成死在头几场战斗。所以**先解决“带着什么到第一幕 Boss”**是当前最大的一块。

这个信号与现有方法的区别：表和价值网络问的是“这一步之后整局走多远”，一张牌只能从它被探索动作选中的那一千来次里估；门口模型问的是“带着这副牌进 Boss 战会怎样”，凡是牌组里有这张牌的门口（几万到十几万个）都是它的样本，而且结果只隔一场战斗。代价是它是观察性的（不是随机对照），并且只管 Boss 战、不管路上。

## 问题

用“过本幕 Boss 的把握”（门口模型）来决定拿哪张牌、升级哪张牌（以及回血还是升级、删哪张牌），能不能让进阶 10 的整局结果超过 R4 最终的规则？

## 做法

**把握模型**（`tools/nosl/boss_readiness.py`）：每幕一个（第一幕、第二幕）逻辑回归，特征如上（每张牌用“有 ≥1 / ≥2 / ≥3 张”“升级的有 ≥1 / ≥2 张”的指示，常见牌和遗物与 Boss 的交互）。在采集数据的门口上拟合，写成一张表 `readiness-*.json`。报告检验集上的对数损失、AUC 和分档的实际通过率。

**把握规则**：加在 R4 最终规则（基础策略 + 价值网络 margin + 表）之上。当前这一幕有模型、Boss 已知（公开信息）时，对“效果能直接从公开状态算出来”的决策，给每个选项算一个 ΔR（这个选项让门口把握的对数几率变化多少）：

- 选牌（战斗奖励的三选一或跳过）：拿这张牌 = 它在这个 Boss 下、按牌组里已有张数取的系数；跳过 = 0。
- 选升级哪张牌：升级它带来的系数变化。
- 臂 B 起：休息点回血还是升级——回血 = HP 系数 ×（能回的血量）；升级 = 最好的那张牌的升级变化。
- 臂 C 起：选删哪张牌——删掉它的系数变化。

选项的得分 = 表里的值（没有就是 0）+ λ × ΔR；得分最高的选项比规则原来选的高出 0.01 以上就换（与表规则同一个门槛）。λ 把对数几率换成结果目标的单位；按“到得了门口的概率 × p(1−p) × 过 Boss 值多少”粗算，进阶 10 第一幕约 0.14。

它只读公开信息（牌组、遗物、HP、是哪个 Boss），不模拟、不搜索；能部署，但原生策略包还不认识它——**本项里实机能跑的仍是 R4 的带表策略包**，采用之后的原生实现另行登记。

**战斗策略不动**：全程用 R4 选中的第 1690 次迭代的检查点。牌组变了之后战斗要不要跟着训，是下一项的事；这里只看局外这一个改动。

### 阶段一：现有数据上的把握模型

臂（都在调参集上各评一次，不再加别的臂）：

| 臂 | 范围 | λ |
|---|---|---|
| 基线 | R4 最终规则 | — |
| A1 / A2 / A3 | 第一幕：选牌 + 选升级哪张 | 0.03 / 0.07 / 0.15 |
| A4 | 同上，不看表（只按把握） | — |
| B | A 里最好的 λ + 第一幕休息点回血还是升级 | 同 |
| C | B 与 A 里较好的那个 + 第一幕选删哪张牌 | 同 |
| D | 以上最好的范围 + 第二幕也用（第二幕的模型） | 同 |

采用标准：调参集结果目标对基线的配对差 ≥ +0.015 且 95% 区间下界 > 0，取其中最高的。

### 阶段二：在新规则下再采一代、重拟合（阶段一有臂被采用才做）

把握模型的依据只到现有牌组的分布为止。用采用的规则加 ε = 0.15 探索采一代（十万局，进阶 0/5/10/10，与 R4 相同的采集方式，种子 `NR5G6T`），门口并入重新拟合，再评“旧模型 / 新模型”两臂（范围与 λ 不变）。新模型比旧模型高 +0.01 以上才换。

### 修订一（2026-10-08 14:52 UTC：阶段一的八个评价已出、D 已按标准采用、阶段二的采集在跑、下面的模型和臂都还没有任何结果时登记）

阶段一的结果（见报告）：只管第一幕 Boss 的把握就把调参集结果目标提高了 +0.035，第二幕也用之后 +0.037；死在第一幕 Boss 的局从 30.0% 降到 22.8%。但同一张表也显示了代价和下一处：死在第一幕路上的从 12.5% 升到 15.0%，多过的那些局大多死在第二幕头几场（死在第 18–25 层的从 26.6% 升到 30.4%）。现在的规则只看 Boss 战，不看路上；而第二幕里它用的是“到了 Boss 门口”的那些牌组拟合的模型，可是进第二幕的局将近一半到不了第 26 层。

所以把“门口”从两个 Boss 推广到一串关口（`tools/nosl/boss_readiness.py --segments`），每个关口一个同样形式的模型，都只用采集数据拟合：

| 关口 | 状态取自 | 算过了 |
|---|---|---|
| S1 第一幕后半段 | 第一幕里第 9 层起的第一个决策 | 走到第 17 层（Boss 层） |
| S2 第一幕 Boss | 第 16 层最后一个决策（已有） | 进第二幕 |
| S3 第二幕前半段 | 第二幕的第一个决策 | 走到第 26 层 |
| S4 第二幕后半段 | 第二幕里第 26 层起的第一个决策 | 走到第 33 层（Boss 层） |
| S5 第二幕 Boss | 第 32 层最后一个决策（已有） | 进第三幕 |

**链式规则**：在第 s 个关口之前（或之中）的决策，选项的 ΔR 是它对后面每个关口的对数几率变化的加权和，权重不调、由数据定：w_j =（从当前关口到 j 都过的概率）×（1 − p_j）× G_j，其中 p_j 是关口 j 的通过率、G_j 是“过了 j 的局”比“死在 j 的局”的平均结果目标高多少，都按进阶分别从拟合数据里量。得分 = 表里的值 + κ × Σ w_j ΔR_j；κ = 1 是这套权重自己的单位（对第一幕 Boss 它给出约 0.17，与阶段一调出来的 0.15 一致）。范围仍是选牌 + 选升级哪张。

臂（调参集上各评一次）：链式 κ = 1、κ = 2。对照是届时有效的规则（D，或阶段二换上的新模型）。采用标准：配对差 ≥ +0.01 且 95% 区间下界 > 0。链式模型与届时有效规则的模型用同样的几代数据拟合。第三幕的关口不做（现有数据里进第三幕的局太少）。

### 阶段一没有臂被采用时

不加臂、不调 λ。改做登记在此的对照：整局固定一套取舍（“风格”）。每局按种子确定一组旋钮——第一幕 / 第二幕休息点升级的 HP 门槛、打精英的 HP 门槛、商店有钱就删牌、选牌的跳过门槛——在带表规则之上整局执行；5 万局进阶 10（种子 `NR5STYLE`），不加 ε。用这批局对旋钮做回归，选出预测最好的一组，在调参集上按同一个采用标准评一次。这回答“成套地变有没有比现在更好的一套”。

## 评价

- 调参集 `NR5TUNE000000–002047`（新种子），2048 局，进阶 10，GPU fp32 贪心。只用来选臂，带选择偏差。
- 旁证（单列）：采用的规则在进阶 0 的 512 局 `NR5DIAG000000–000511` 上评一次。
- 机制指标（都报）：走到第一幕 Boss 门口的比例、门口上过 Boss 的比例、进第二幕、进第三幕。
- 留出集 `NR5EVAL000000–002047`：R4 最终组合与本项最终组合各 2048 局，只跑一次。本项最终组合 = 被采用的最后一个规则；没有臂被采用就不跑留出，结论写“无效”。
- 留出判据：结果目标配对差的 95% 下界 > 0 记为有效。进阶 10 的任何通关单独报告种子并做正版回放；0 通关不称高水平。
- 最终组合的留出轨迹按种子号取前 64 局做 TestMode=false 的正版回放。
